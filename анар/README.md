# anar — атлас-монтаж мышц для роликов тренера Анара

Мышцы поверх тела, как в анатомическом атласе: рабочие красные с жёлтым контуром, вспомогательные оранжевые, стабилизаторы серые с оранжевым краем. Импульсы силы бегут по пути «гриф → кисть → локоть → плечо → мышца → таз». Стоп-кадры из 4K с наездом, крупной стрелкой и подписью. В конце идёт полный повтор без стопов.

Эталон — тяга верхнего блока, версия v7c (04.11.2026).

## Порядок запуска

Все скрипты лежат в `scripts/`. Запускать из рабочей папки, где лежит `seg.mp4`.

1. Отрезок: кроп из 4K по центру торса (~1.15×), 1080×1920, `seg.mp4`.
2. `python3 track2.py 540 1000 2000`, потом `mv pose2.json pa.json; mv masks2 ma`.
   `python3 track2.py 540 1150 1750`, потом `mv pose2.json pb.json; mv masks2 mb`.
   Модель: `pose_landmark_full.tflite` из колеса `mediapipe==0.10.14` (cp312, `pip download --no-deps`), положить в `/tmp/pose_landmarks_detector.tflite`. Интерпретатор: `pip install ai-edge-litert`.
3. `python3 glue.py`: приклейка корсета к спине оптическим потоком.
4. `python3 arms.py`: руки, поза + оптический поток.
5. `python3 axis.py`: ось строго по позвоночнику, вертикаль, симметрия.
6. `python3 r7.py`: живые кадры, стопы из 4K (`hi6_<кадр>.png`), сборка в `seq7/`. Список стопов в `FREEZES`.
7. Сборка mp4 со звуком исходника с той же секунды (ffmpeg).

## Правила стиля (из правок Алекса)

- Видео только со штатива.
- **Корсет после посадки неподвижен**: одна позиция и один размер (медиана по сидячим кадрам) до самого конца. Иначе на последнем повторе опущенные локти сбивают силуэт и корсет уезжает.
- **Каркас по оси шеи**: середина корсета = середина шеи по силуэту (медиана по кадрам). Ось строго вертикальная в выровненном кадре, стороны зеркальные. Перед отдачей проверить по кадрам, что ось проходит через центр шеи и головы.
- Корсет закрывает всю зону без дыр. Формы гладкие (сплайны Катмулла-Рома, перо по краю, объём), без углов.
- Палитра из рефа (BGR): красный 28,49,217 / блик 66,104,225; оранжевый 30,105,220; серый 152,162,169; жёлтый 49,183,233, свечение 115,220,249.
- Верхняя мышца перекрывает нижнюю чисто. Цвет кладётся через умножение (≈55% multiply), прозрачность ~0.80 / 0.70 / 0.62.
- Импульсы бегут только в фазе усилия и медленно.
- Статичных стрелок на теле и по краям нет. Одна крупная стрелка по смыслу — только на стопе.
- Стрелки и подписи рисуются **после** выравнивания горизонта, строго горизонтально или вертикально.
- Подпись стоит на месте внизу по центру: заголовок КАПСОМ + одна короткая строка.
- Хват показывать так, чтобы были видны обе руки. Кисти брать из второго прогона трекинга (`pb.json`).
- В конце полный повтор без стопов: брать следующий реальный повтор, а не вставку.
- Длина рилса — целиться в 15–18 с.

## Стопы для тяги верхнего блока

1. ХВАТ ЧУТЬ ШИРЕ ПЛЕЧ / прямой хват сверху
2. СПИНА РОВНАЯ / корпус не раскачивай
3. ШИРОЧАЙШИЕ ТЯНУТСЯ / руки вверх — спина вытягивается
4. ЛОКТИ ВНИЗ К РЁБРАМ / тяни локтями, не кистями
5. ГРУДНЫЕ ВВЕРХ + ЛОПАТКИ ВНИЗ И ВМЕСТЕ / сведи в нижней точке

Подсказки по технике общепринятые, первоисточником не сверены. Подтверждать у Анара.
